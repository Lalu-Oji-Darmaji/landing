Git Collaborator

Git collaborator adalah seseorang yang diberi akses untuk berkontribusi langsung ke sebuah repositori Git, seperti menambahkan, mengubah, atau mengelola kode. Di platform seperti GitHub, collaborator biasanya diundang oleh pemilik repositori untuk bekerja sama dalam proyek secara langsung.
